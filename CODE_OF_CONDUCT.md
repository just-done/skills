# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1. Everyone who takes part in issues, pull requests and discussions in this
repository is expected to uphold it.

## Reporting

Report behavior that violates the Code of Conduct to **abuse@just-done.ai**. Every report
is reviewed and handled confidentially.

Maintainers may remove, edit or reject comments, commits, issues and pull requests that do
not follow the Code of Conduct, and may restrict participation for anyone who repeatedly
does not.
